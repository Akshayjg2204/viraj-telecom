## ✨ Design & Engineering Highlights

- **🎧 Comprehensive Services & Catalog Showcase:** Multi-tier service breakdown detailing component-level repair for audiophile headphones, Sennheiser enterprise call center headsets, and industrial electronics.
- **⚡ Next.js 16 & React 19 Architecture:** Leverages concurrent rendering and App Router for instant page transitions and zero-layout-shift client routing.
- **🎨 Tailwind CSS v4 & Radix Primitives:** Built with a clean, accessible design system featuring interactive carousels (`Embla Carousel`), expandable accordions, and hover cards.
- **🌓 Seamless Dual Theme Engine:** Fully integrated `next-themes` engine supporting automatic system preferences and manual Light/Dark mode toggling.
- **📱 Fully Responsive & Cross-Device Optimized:** Mobile-first layout scaling from compact smartphones up to 4K desktop displays with fluid typography.

## 🛠️ Tech Stack

| Technology | Purpose |
| :--- | :--- |
| **Next.js 16** | App Router, server-rendered layouts, and optimized static asset pipeline |
| **React 19** | Concurrent UI component architecture |
| **TypeScript** | Strict compile-time typing across all UI modules and service contracts |
| **Tailwind CSS v4** | Hardware-accelerated utility styling paired with modern CSS variables |
| **Framer Motion** | Fluid scroll entrance animations and layout state transitions |
| **Radix UI / shadcn** | Accessible headless primitives (Dialogs, Tabs, Menus, Accordions) |
| **Embla Carousel** | Touch-friendly responsive product and review carousels |
| **Lucide React** | Consistent vector iconography |

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18+ or 20+
- pnpm or npm

```bash
# 1. Clone the repository
git clone https://github.com/Akshayjg2204/viraj-telecom.git
cd viraj-telecom

# 2. Install dependencies
pnpm install
# or: npm install

# 3. Start development server
pnpm dev
# or: npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Building for Production
```bash
pnpm build
# or: npm run build
```
